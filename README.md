# Эстетика — концепция сайта салона в Таганроге

Интерактивный демонстрационный сайт для предложения владельцу. Не является официальным сайтом салона. Статический HTML, CSS, JavaScript без сборки, аналитики, cookies и хранения данных посетителей.

## Публикация

https://kevorik.github.io/estetika-taganrog-demo/

GitHub Pages публикует содержимое `dist/` через GitHub Actions. Бесплатный публичный доступ без входа в ChatGPT. Для локального просмотра: `python3 -m http.server 4173 --directory dist`.

## Сценарии

- 5 направлений услуг с ценами и длительностью, доступное переключение вкладок с клавиатуры.
- Фотогалерея с увеличением, стрелками и закрытием по Escape.
- Выбор онлайн-записи или связи с администратором.
- Переход в существующий YCLIENTS, телефон, мессенджеры и маршрут.
- Мобильная навигация и постоянная кнопка записи.
- Анимации появления, мягкий параллакс и поддержка prefers-reduced-motion.

## Изображения

Главный `dist/assets/hero-editorial.jpg` — концептуальный AI-портрет, создан встроенным Imagegen. Не фотография клиентки салона и не пример работы мастеров. Это указано в alt и окне «О демо». Промпт в `IMAGE-PROMPT.txt`.

Работы и пространство взяты из публичной галереи для презентации владельцу. Перед коммерческим запуском владелец должен утвердить материалы, актуальный прайс и права на фотографии. Дизайн подарочного сертификата — концепт. Подтверждено наличие услуги сертификата, но его номинал и условия не придуманы. Сайт исключён из индексации robots.txt и meta robots.

## Перед официальным запуском

Согласовать дизайн и контент с владельцем, заменить концептуальный портрет при необходимости, утвердить фотографии, проверить цены и реквизиты, подключить домен. Онлайн-запись уже ведёт в существующий сервис салона. Никакие тестовые заявки не отправлялись.
